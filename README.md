# Thursday 26 November 2026: The World in One Day — from Mana's 40 stories

Entry for the make.fun competition [news-image-20261126](https://make.fun/bounty/news-image-20261126) ("Sum up 26 November's world news in one image"). The program `main.py` copies the finished one-page newspaper image (1024×1024, 40 stories from Thursday 26 November 2026, 7 regions) to `/output/entry.png`.
